# gllai-layer2-training

This repository contains training, conditioning, and evaluation assets
for **GLLAI Layer 2 (Conversational Behaviour Layer)**.

## Scope
- Behavioural conditioning ONLY
- No linguistic authority
- No grammar, meaning, or translation learning

## Data Source
All datasets are pulled read-only from:
`gllai-datasets/layer2/v1/`

## What this repo does
- Shapes conversational tone
- Improves hesitation, back-channeling, refusal recovery
- Makes the assistant feel Ghanaian without learning language rules

## What this repo must NEVER do
- Train correctness or truth
- Modify datasets
- Feed Layer 2 data into Layer 1
- Teach language meaning

## Status
- Dataset: v1 (frozen)
- Training: scaffolded
